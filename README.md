## Projetos em destaque

| Projeto | Área | O que faz |
|:--|:--:|:--|
| **[GeoForest-IA](https://github.com/alvaro209890/GeoForest-IA)** | GIS + IA | Plataforma de análise florestal com IA: detecção de erros de geometria, análise de containment e conferência de projetos geográficos no padrão SIMCAR |
| **[mapas-facil](https://github.com/alvaro209890/mapas-facil)** | GIS + IA | Chat de IA que gera mapas `.mxd` (ArcMap) e `.pdf` direto no PC do usuário, no padrão cartográfico IMAP |
| **[AlertaCAR](https://github.com/alvaro209890/AlertaCAR)** | GIS + IA | Monitoramento de CARs com alertas de desmatamento (SCCON) e da SEMA-MT entregues por WhatsApp |
| **[DeepSeekGIS-Toolbox](https://github.com/alvaro209890/DeepSeekGIS-Toolbox)** | GIS + IA | Toolbox que une geoprocessamento e LLM para análise espacial |
| **[CodingPro](https://github.com/alvaro209890/CodingPro)** | Agentes | CLI de código com IA (DeepSeek), 100% em português, com TUI temática |
| **[atlas-assistente-pessoal](https://github.com/alvaro209890/atlas-assistente-pessoal)** | Agentes | Assistente pessoal multiusuário com WhatsApp, Trello, lembretes e segundo cérebro |
| **[AquiResolve](https://github.com/alvaro209890/AquiResolve)** | Produto | App + painel de serviços urbanos com geolocalização, chat, pagamento e avaliação bidirecional |
| **[aqui-log](https://github.com/alvaro209890/aqui-log)** | Produto | Plataforma de logística urbana conectando empresas e entregadores |
| **[VendaFacil_PDV](https://github.com/alvaro209890/VendaFacil_PDV)** | Produto | PDV offline-first para pequenos comércios, com emissão de NFC-e (SEFAZ-MT) |
